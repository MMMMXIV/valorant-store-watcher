# VALORANT Store Watcher（非公式）

VALORANT のデイリーストアに **ウィッシュリストのスキンが並んだら Discord に画像付きで通知する** Windows 用デスクトップアプリです。

> ⚠️ **本アプリは非公式のファンメイドツールです。** Riot Games とは一切関係なく、承認も受けていません。
> VALORANT および関連する名称・画像は Riot Games, Inc. の商標です。

## 1. まず知っておいてほしいこと（自動取得の実現状況）

| 項目 | 状況 |
|---|---|
| Riot公式APIで個人ストアを取得 | ❌ 提供されていません（ストア監視は公式APIの未承認用途） |
| **Riotアカウント方式（非公式）** | ✅ **搭載済み（初期状態は無効）**。リスクに同意して有効化すると、**自分のアカウントの実際のストアを毎日自動取得**します |
| パスワードの扱い | **アプリは受け取りません。** Riot公式のログインページに直接入力します |
| 2段階認証・CAPTCHA | Riotのページで**自分で入力**します（回避処理は一切ありません） |
| 保存するもの | Riotが発行するログインCookie（`ssid` など）のみ。Windowsの暗号化機能（DPAPI）で保護 |

### ⚠️ Riotアカウント方式のリスク（必ずお読みください）
- ゲームクライアント用の**非公開API**を使う非公式な方法です。Riotの利用規約に反する可能性があり、**アカウントに制限がかかるリスクはゼロではありません**。
- Riotの仕様変更で予告なく使えなくなることがあります。
- ログインCookieは**パスワードと同じくらい重要**です。他人に渡さないでください。**自分のアカウントだけ**で使ってください。
- ログインは定期的に切れます（Riotの仕様）。切れたらアプリとDiscordでお知らせするので、設定画面から再ログインしてください。

非公式方式を使いたくない場合は、次の方法も使えます。
- **テスト用ストア（Mock）**：疑似データで通知の流れを確認
- **手動取り込み**：ゲーム内で見た4スキンを選んで入力（約30秒）
- **JSONファイル監視**：自分で用意したJSONファイルを毎日読み込む

調査の詳細は [docs/RESEARCH.md](docs/RESEARCH.md) を参照してください。

### Riotアカウントでログインする手順
1. ［設定］→［Riotアカウント連携（非公式）］のリスク説明を読み、チェックを入れて **［同意して有効にする］**。
2. **［Riot公式ページでログイン］** を押すと別ウィンドウが開きます。タイトルが `🔒 auth.riotgames.com — Riot公式ログインページ` になっていることを確認します。
3. Riot ID・パスワード（2段階認証のコード）を入力してログインします。
4. ウィンドウが自動で閉じ、「ログイン済み: あなたのRiot ID」と表示され、すぐに今日のストアを取得します。
5. 地域は自動判定されます（日本は AP）。うまくいかない場合は［地域］で選んでください。

**ログインウィンドウがうまく動かない場合**：［ssid を貼り付け］を開き、普段のブラウザでRiotにログイン →
F12 → Application → Cookies → `https://auth.riotgames.com` の `ssid` の値を貼り付けます。

**連携解除**：［連携解除］を押すと、保存されたログインCookieとアカウント情報を削除します。

## 2. できること

- 🔎 **スキンカタログ**：全武器のスキンを日本語・英語で検索、武器・レアリティで絞り込み
- ❤️ **ウィッシュリスト**：登録・削除・ドラッグで並べ替え・優先度（高／中／低）
- 🔐 **自分のストアを自動取得**（Riotアカウント方式・非公式・要同意）
- 🛒 **ストア照合**：ストアの4スキンとウィッシュリストをIDで照合（スキン・レベル・クロマIDを自動で正規化）
- 🔔 **Discord通知**：画像付きで通知。**同じストア期間には二重通知しません**。翌日以降にまた並べば再通知します
- ⏰ **自動監視**：毎日 9:05（日本時間）にチェック。失敗時は 5→15→30→60分後に再試行
- 💤 **起動時の確認**：PCが止まっていた間のストアは、次の起動・スリープ復帰時にすぐ確認
- 📜 **履歴**：ストア履歴、過去に並んだスキン、通知履歴、エラー履歴
- 🖥️ **タスクトレイ常駐**：ウィンドウを閉じても監視を継続。Windowsログイン時の自動起動

## 3. インストール方法

1. `VALORANT-Store-Watcher-Setup-1.1.0.exe` をダブルクリックします。
2. 「WindowsによってPCが保護されました」と表示された場合は、**［詳細情報］→［実行］** を押してください。
   （コード署名証明書を使っていないため表示されます）
3. 画面の案内に従って［次へ］を押すとインストールが完了します。管理者権限は不要です。
4. デスクトップの **VALORANT Store Watcher** アイコンから起動します。

**アンインストール**：Windowsの「設定 → アプリ → インストールされているアプリ」から削除できます。
ウィッシュリストや履歴も消したい場合は、途中の確認で［はい］を選んでください。

## 4. はじめての使い方（5分）

1. **アプリを起動**すると、スキン情報を自動でダウンロードします（初回のみ数秒）。
2. 左メニューの **［スキンカタログ］** で欲しいスキンを検索します（例：`リーヴァー`、`Reaver`）。
3. スキンカードの **［ウィッシュリストに追加］** を押します。
4. **［設定］→［Discord Webhook］** にWebhook URLを貼り付けて［保存］、［テスト通知］でDiscordに届くか確認します（→ [5章](#5-discord-webhook-の設定手順)）。
5. 動作確認：［設定］→［ストア取得方法］で **テスト用ストア（Mock）** を選び、
   **「ウィッシュリストのスキンを必ず含める」** をONにします。
6. **［ダッシュボード］→［今すぐチェック］** を押すと、Discordに画像付きの通知が届きます。
7. もう一度［今すぐチェック］を押しても、**同じストアなので通知は来ません**（二重通知防止）。

## 5. Discord Webhook の設定手順

1. Discordで通知を受け取りたい **サーバーのチャンネル** の ⚙️（チャンネルの編集）を開きます。
2. **［連携サービス］→［ウェブフック］→［新しいウェブフック］** を押します。
3. 名前（例：Store Watcher）を付け、**［ウェブフックURLをコピー］** を押します。
4. アプリの **［設定］→［Discord Webhook］** に貼り付けて **［保存］** を押します。
5. **［テスト通知］** を押し、チャンネルに「✅ テスト通知です」と届けば完了です。

> 🔒 Webhook URLは **Windowsの資格情報保護機能（DPAPI）で暗号化** して保存され、画面にも再表示されません。
> URLを知っている人は誰でもそのチャンネルに投稿できるので、**他人に教えないでください。**
> 漏れてしまった場合は、Discord側でそのウェブフックを削除して作り直してください。

### 通知条件（［設定］→［通知条件］）
| 設定 | 内容 |
|---|---|
| Discord通知を有効にする | OFFにするとすべての通知を停止（取得・記録は続く） |
| ウィッシュリスト一致時に通知 | 登録スキンが並んだときだけ通知（おすすめ） |
| 毎日のストア全体を通知 | 毎日その日の4スキンを1回通知 |
| エラー発生時に通知 | 取得に失敗したとき（1日1回まで） |

## 6. ストアの取り込み方法

### A. スキンを選んで入力（いちばん簡単）
［ダッシュボード］→［ストアを手動入力］→［スキンを選んで入力］で、ゲーム内のストアに並んでいる4スキンを検索して選び、価格（VP）を入れて［取り込んで照合する］。

### B. JSONを貼り付け／JSONファイル監視
次の形式に対応しています。

**アプリ独自形式（vsw-store-v1）**
```json
{
  "format": "vsw-store-v1",
  "date": "2026-11-21",
  "offers": [
    { "id": "スキン・レベル・クロマのどれかのUUID", "price": 1775 },
    { "name": "RGX 11z Pro Vandal", "price": 2175 }
  ]
}
```
- `id` はスキン本体・スキンレベル・クロマのどのIDでもOK（自動で本体IDに変換して照合します）
- `id` が分からない場合は `name`（日本語または英語の正式名）でも指定できます
- `date` はストアの日付（日本時間9:00に切り替わる日）。省略すると今日

**ストアAPI形式**：`SkinsPanelLayout`（`SingleItemStoreOffers` など）を含むJSONもそのまま読み込めます。

**JSONファイル監視**：［設定］→［ストア取得方法］→［JSONファイル監視］でファイルを選ぶと、毎日の自動チェック時にそのファイルを読み込みます。
ファイルの用意方法は利用者に委ねられます（非公式な方法で取得したデータを使う場合のリスクは利用者の責任となります）。

## 7. 自動監視の設定方法

［設定］→［自動チェック］で変更できます。

| 項目 | 初期値 | 説明 |
|---|---|---|
| 自動チェック | ON | テスト用ストア・JSONファイル監視で有効 |
| チェック時刻 | 09:05 | ストア更新（日本時間9:00）の5分後 |
| タイムゾーン | Asia/Tokyo | |
| ストア更新後の待ち時間 | 5分 | 取得元が更新時刻を返す場合はそちらを優先 |
| 失敗時の再試行 | 5→15→30→60分後 | すべて失敗したら翌日の定時まで待機 |

- **同じストア期間に何度チェックしても通知は1回だけ**です。
- 無駄な通信を防ぐため、自動チェックは最低10分間隔、今日のストアを確認済みなら次の更新まで取得しません。
- ⚠️ **PCの電源が切れている間やスリープ中は監視できません。** 次に起動・復帰したとき、未確認のストアがあればすぐに確認します。

### タスクトレイと自動起動（［設定］→［Windows］）
- 「Windowsログイン時に自動起動」をONにすると、PCにログインしたときトレイで自動的に起動します。
- ウィンドウの［×］を押してもトレイ（画面右下）で監視を続けます。
- トレイアイコンの右クリックで「アプリを開く／今すぐチェック／監視の一時停止／終了」ができます。

## 8. スキンデータの更新方法

- スキン名・画像は有志の非公式サービス **Valorant-API（valorant-api.com）** から取得します。
- アプリは起動時と6時間ごとにゲームバージョンを確認し、**新スキンが追加されると自動で取り込みます**。
- 手動で更新するには ［スキンカタログ］→［データ更新］ または ［設定］→［スキンデータ］→［今すぐ更新］。
- カタログから消えたスキンも、ウィッシュリストや履歴からは消えません（「カタログから削除済み」と表示）。

## 9. セキュリティ上の注意

- **Riotのパスワードは一切扱いません。** ログインはRiot公式ページで行い、アプリは入力内容を読み取りません（スクリプト注入なし・使い捨てのブラウザセッション）。
- Riotのログイン Cookie は DPAPI で暗号化して保存し、［連携解除］で完全に削除します。トークンはメモリ上のみで保持します。
- 「パスワードを入れれば自動取得できる」とうたう他人のBot等にパスワードを渡すのは避けてください。
- Webhook URLは Windows DPAPI で暗号化して保存（`%APPDATA%\VALORANT Store Watcher\secrets.json`）。暗号化が使えない環境では保存を拒否します。
- 画面（Renderer）には秘密情報を渡しません。Electronの `contextIsolation` 有効・`nodeIntegration` 無効・`sandbox` 有効・CSP設定済み。
- アプリ内部の通信（IPC）はすべて入力値を検証しています。外部通信はすべてタイムアウト付きです。
- ログにはWebhook URLのトークン部分・Bearerトークン・JWT・Cookieを自動でマスクして記録します。
- データの保存先：`%APPDATA%\VALORANT Store Watcher\`（`vsw.sqlite` = ウィッシュリスト・履歴、`logs\` = ログ）。
- 削除したい場合：［設定］→ Webhookの［削除］で認証情報を破棄できます。

## 10. よくある質問

**Q. 毎日自動で本物のストアを取ってくれる？**
A. ［設定］でリスクに同意してRiotアカウントでログインすれば、毎日自動で取得します（1章）。非公式な方法なので、リスクを理解したうえで自分のアカウントだけで使ってください。

**Q. 「Riotへの再ログインが必要です」と出た**
A. Riotのログイン情報の有効期限が切れました。［設定］→［Riotアカウント連携］→［Riotに再ログイン］を押してください。

**Q. 通知が来ない**
A. ①［設定］でWebhookが「設定済み」か ②［テスト通知］が届くか ③通知条件がONか ④［履歴］→［Discord通知履歴］／［エラー履歴］を確認してください。送信に失敗した通知は次回のチェックで自動的に再送します。

**Q. 同じスキンがまた来たのに通知されない**
A. 同じストア期間（その日の9:00〜翌9:00）では1回だけ通知します。翌日以降に再登場した場合は再度通知されます。

**Q. 画面に「テストモード」と出ている**
A. 取得方法が「テスト用ストア（Mock）」になっています。表示されているのは疑似データです。
